# T-48 Settings design brief (visual-reviewer, 2026-11-12; from qa/T-48-pre)
Source: design.css tokens + Fleet look (domino-app-guidelines not installed). No new colors/components.
- Header: "Signed in as <owner> (workspace)" meta line (13px muted, name 600), data-testid settings-signed-in; other modes "Signed in as <user>" or nothing.
- Exactly four cards in order Demo, Integrations, Credentials, Access (rename "Demo mode"->Demo, "Platform credentials"->Credentials, move Credentials below Integrations; remove per-platform sub-nav entries). 1440: 200px sticky section nav (4 links), 1000px column. 1024: sticky pill row, single column; Credentials platform groups 1-col below 1100px. Rows <=52px, card heads 56px, no 17px top gap, no card-in-card.
- Demo card (settings-card-demo, first): head "Demo" + On/Off pill; role=switch "Demo mode"; state line ("Demo mode is off. You are seeing your real data." / "...on. You are seeing simulated data.") + helper "Turning it on switches to a separate demo database with simulated agents, runs and approver. Your real data is never changed." Off with no real data: dialog "Turn demo mode off?" / "No real data is loaded yet, so Fleet will be empty until you register or import agents." / button "Turn off demo mode". Env-locked: disabled + "Set by environment variable ACT_DEMO_MODE". Busy "Switching…", inline error + Retry. Banner (admins only): "Demo settings" link next to "Reset demo" -> #/settings#st-demo.
- Field row: grid [label+help 40%][control 1fr][status 120px], stacks <800px. Label 14/600, help 13 muted with env var in <code>. Empty: format placeholder, "Not set"; Save only when dirty. Saved: "Set" + "Changed by X, date", "Saved" tick 4s. Env-locked: read-only/masked + "Set by environment variable ACT_X" (replaces "Set by project variable"), no Clear/Replace. Secret: •••••••• + Set + Replace/Clear; unreadable -> "Re-enter" warn badge. Clear dialog: name "Clear key"/"Clear value" as title + confirm; remove ds-sr "(confirm)" (Settings.jsx:187); label in body "Clear <label>? …". Credentials: 4 platform groups flat, 2-col, h3 + status pill (Configured/Incomplete/Not configured); move Break-classifier access key here. Key warning: compact alert in the Credentials card head.
- Access: fixed owner chip (lock, "Project owner · always admin", admins-fixed-owner, no remove); "Additional admins" chips + add input, help "Usernames, comma-separated. Admins can change every setting on this page."; env-locked from ACT_ADMINS read-only.
- Nav: Settings always last, gear icon nav-settings-icon (16px, aria-hidden), active on #/settings.
- Non-admin: full 4-card layout read-only + info alert "You can view these settings but not change them. Only the project owner and listed admins can edit. Ask <owner> to add you under Access." 403-without-data fallback: lock card "Settings are read-only for you". Signed out: card "Sign in to view Settings" / "Sign in to Domino, then reload this page. Settings can be changed by the project owner and listed admins." / button "Reload after signing in". No admins configured: "No owner or admins are configured. Set ACT_ADMINS to a list of usernames." Loading: 4-card skeleton; error: card + "Try again".
- Fixes: dead space under lock state (non-admin/signed-out); Integrations status column ~150px dead space; blank platform inputs; banner 104px repeats "Demo mode: simulated data" — collapse stand-in chips behind the "6 stand-ins" disclosure.
